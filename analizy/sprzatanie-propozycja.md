# Propozycja sprzatania repozytorium

To jest lista propozycji po sprawdzeniu uzycia. Nic z tej listy nie zostalo usuniete.

| Sciezka | Co to jest | Czy uzywane | Propozycja | Ryzyko usuniecia |
| --- | --- | --- | --- | --- |
| `next-app/` | Nieśledzony eksperyment Next.js/TinaCMS. | Nie jest uzywane przez aktualny build Docusaurusa. Sprawdzone: `rg "next-app\|tina\|__generated__" -g '!build/**' -g '!node_modules/**'`; trafienia tylko w `ARCHITEKTURA.md`, `CLAUDE.md` i samym `next-app/`. | Kandydat do usuniecia po decyzji wlasciciela, ale `CLAUDE.md` mowi, zeby nie usuwac, chyba ze Lukasz wroci do tematu. | Srednie: mozna stracic zaparkowany eksperyment i kontekst migracji. |
| `Edytuj-Strone.bat` | Skrót Windows do uruchamiania strony i lokalnego Decap CMS. | Uzywane przez workflow edycji CMS. Sprawdzone: `rg "Edytuj-Strone\|Publikuj-Zmiany" -g '!build/**' -g '!node_modules/**'` oraz `Get-Content Edytuj-Strone.bat`; odwoluje sie do `npm run edit` i `/admin/`. | Zostawic, jezeli wlasciciel edytuje tresc przez CMS. Ewentualnie dopisac do README jako oficjalna sciezke edycji. | Srednie: usuniecie pogorszy nietechniczny workflow edycji. |
| `Publikuj-Zmiany.bat` | Skrót Windows do publikowania zmian przez `git add -A`, `git commit`, `git push`. | Powiazany z CMS. Sprawdzone: `rg "Edytuj-Strone\|Publikuj-Zmiany" -g '!build/**' -g '!node_modules/**'` oraz `Get-Content Publikuj-Zmiany.bat`. | Zostawic tylko jesli wlasciciel swiadomie uzywa. Do rozwazenia: zastapic bezpieczniejsza instrukcja, bo skrypt publikuje wszystko z worktree. | Wysokie: usuniecie moze popsuc prosty workflow, ale zostawienie ma ryzyko przypadkowego commitowania. |
| `static/admin/` | Panel Decap CMS dostepny pod `/admin/`. | Technicznie nie jest czescia publicznego SEO; jest blokowany w `static/robots.txt`. Sprawdzone: `rg "admin\|decap\|cms\|config.yml" static src content scripts package.json docusaurus.config.js README.md`. Wyniki wskazuja `npm run edit`, `decap-server`, `static/admin/index.html` i `static/admin/config.yml`. | Techniczny kandydat do usuniecia, ale decyzja wlasciciela: CMS zostaje w repo. | Wysokie: usuniecie zamknie lokalna edycje przez CMS. |
| `README.md` | Domyslny README Docusaurusa. | Nie jest uzywany przez build. Sprawdzone: `Get-Content README.md -TotalCount 80`; tresc to standardowy opis Docusaurusa, bez informacji o poCADuchy, CMS i publikacji. | Zastapic krotkim README projektu: start, build, edycja CMS, publikacja, uwagi o danych generowanych. | Niskie: to dokumentacja, ale obecna tresc jest mylaca. |
| `src/data/wiedza-wzory.json`, `src/data/wiedza-materialy.json`, `src/data/wiedza-elementy.json` | Puste manifesty kategorii bazy wiedzy. | Uzywane mimo pustej zawartosci. Sprawdzone: `Get-ChildItem src\data -File | Select Name,Length` oraz `rg "src/data\|@site/src/data|\.\./data" src scripts docusaurus.config.js`; pliki maja po 3 bajty i sa importowane w `src/pages/wiedza.js`, a generuje je `scripts/build-content-pages.mjs`. | Nie usuwac. Wypelnic, gdy powstana artykuly wiedzy. | Srednie: usuniecie popsuje importy strony `/wiedza`. |
| `src/data/blog-posts.json`, `src/data/episodes.json`, `src/data/subscribers.json`, `src/data/image-sizes.json` | Wygenerowane dane dla bloga, YouTube, liczby subskrybentow i wymiarow obrazow. | Uzywane. Sprawdzone: `rg "src/data\|@site/src/data|\.\./data" src scripts docusaurus.config.js`; kazdy plik ma import w `src/pages` albo `src/components`, a generatory sa w `prebuild`. | Nie usuwac. Ewentualnie dopisac w README, ze sa generowane. | Wysokie: usuniecie popsuje build albo layout obrazow. |
| `static/img/favicon.ico` | Historyczny plik favicon ICO. | Brak odwolania tekstowego poza skanem obrazow. Sprawdzone: skrypt Node porownujacy `static/img` z odwolaniami w repo pokazal tylko `/img/favicon.ico`; dodatkowo `rg "favicon\.ico\|pocaduchy-logo\.png" src content static docusaurus.config.js package.json scripts` pokazuje, ze Docusaurus uzywa `img/pocaduchy-logo.png`. | Kandydat do usuniecia albo zostawienia jako fallback dla starszych przegladarek. Decyzja wlasciciela. | Niskie do sredniego: nowy favicon jest PNG, ale ICO bywa oczekiwany przez narzedzia zewnetrzne. |
| `static/img/` poza `favicon.ico` | Obrazy bloga, logo i OG image. | Uzywane. Sprawdzone tym samym skryptem Node porownujacym `static/img` z odwolaniami w repo; jedyny brak odwolania to `/img/favicon.ico`. | Nie usuwac. Osobny temat to optymalizacja/WebP, nie sprzatanie. | Wysokie: usuniecie psuje artykuly, dane strukturalne albo udostepnianie. |
| `package.json`: `clsx`, `@docusaurus/faster`, `@mdx-js/react` | Bezposrednie zaleznosci bez jawnych importow w kodzie aplikacji. | Brak jawnego uzycia poza `package.json`/`package-lock.json`. Sprawdzone: `rg "@mdx-js/react\|clsx\|@docusaurus/faster" package.json package-lock.json src scripts docusaurus.config.js static -g '!build/**' -g '!node_modules/**'`. | Kandydaci do dalszej weryfikacji narzedziem typu depcheck albo testem usuniecia na osobnej galezi. Nie usuwac mechanicznie, bo Docusaurus moze wymagac ich jako peer/opcjonalnych zaleznosci. | Srednie: mozna usunac zaleznosc potrzebna przez Docusaurusa lub przyszle MDX. |
| `package.json`: `katex`, `react-markdown`, `rehype-katex`, `remark-gfm`, `remark-math`, `image-size`, `concurrently`, `decap-server`, `prism-react-renderer` | Zaleznosci renderowania blokow, generowania wymiarow, CMS i motywu kodu. | Uzywane. Sprawdzone: `rg "image-size\|katex\|prism-react-renderer\|react-markdown\|rehype-katex\|remark-gfm\|remark-math\|concurrently\|decap-server" package.json src scripts docusaurus.config.js static`. | Nie usuwac. `katex` jest obecnie potrzebny dla obslugi przyszlych blokow `wzor`, mimo ze aktualny build raportuje `wzory=0`. | Srednie do wysokiego: usuniecie popsuje build, CMS albo przyszle wzory. |
| `src/pages/*.js` i `src/pages/blog/*.js` | Reczne strony Docusaurusa, w tym wygenerowane strony artykulow. | Sa linkowane lub wynikaja z manifestow. Sprawdzone: skrypt Node liczacy wystapienia tras w repo po pominieciu `build`, `node_modules`, `.git`, `next-app`; wszystkie trasy poza `/` mialy dodatnia liczbe odwolowan, np. `/o-mnie 26`, `/odcinki 23`, `/uslugi 33`, `/wiedza 64`, artykuly bloga 12-36. | Brak propozycji usuniecia. Przy blogu lepszym porzadkiem byloby dokumentowac, ze pliki sa generowane przez `scripts/build-content-pages.mjs`. | Wysokie: usuniecie strony usuwa publiczny URL albo artykul. |
